
# Contribution Guidelines

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines expectations for contributors to the project.

---

# Contributor Responsibilities

Contributors should:

- Follow approved documentation.
- Respect project structure.
- Preserve code quality.
- Test their changes.
- Document significant modifications.

---

# Reviews

All significant changes should be reviewed before merging.

---

# Collaboration

Contributors should:

- Communicate clearly.
- Keep changes focused.
- Avoid unnecessary conflicts.

---

# Documentation

Behavioral changes require corresponding documentation updates.
