
# Environment Setup

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the principles for preparing development environments.

---

# Objectives

Development environments should:

- Be reproducible.
- Support project requirements.
- Remain consistent across contributors.

---

# Environment Categories

Typical environments include:

- Development
- Testing
- Production

---

# Configuration

Environment-specific configuration should remain separate from application source code.

---

# Security

Sensitive information shall not be committed to source control.
