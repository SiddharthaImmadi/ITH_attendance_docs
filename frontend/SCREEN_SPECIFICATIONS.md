
# Screen Specifications

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the primary screens of the Attendance Management System and their responsibilities.

It describes what each screen presents to the user without specifying visual implementation details.

---

# Login Screen

## Purpose

Authenticate registered users.

### Primary Functions

- Enter credentials
- Submit login request
- Display authentication errors

---

# Dashboard

## Purpose

Provide an overview of the volunteer's current attendance status.

### Typical Information

- Current event
- Attendance status
- Presence status
- Active notifications

---

# Event Session Screen

## Purpose

Display available volunteering sessions.

### Primary Functions

- View available sessions
- View session details
- Begin attendance process

---

# Check-in Screen

## Purpose

Guide the volunteer through attendance check-in.

### Primary Functions

- Verify location
- Capture identity verification
- Submit check-in request

---

# Active Attendance Screen

## Purpose

Display the volunteer's active attendance session.

### Typical Information

- Event information
- Attendance timer
- Presence status
- Current venue status

### Primary Functions

- View attendance information
- Initiate check-out

---

# Leave Request Screen

## Purpose

Allow volunteers to submit leave requests after leaving the venue.

### Primary Functions

- Select leave type
- Select leave reason
- Enter explanation
- Submit request

---

# Reports Screen

## Purpose

Display attendance history and report information.

### Primary Functions

- View attendance history
- View presence timeline
- View leave history

---

# Administration Dashboard

## Purpose

Provide administrative management capabilities.

### Primary Functions

- Review leave requests
- Manage restrictions
- Manage venue boundaries
- View reports
