# ITH Attendance Management System Documentation

## Purpose

This repository serves as the **single source of truth** for the ITH Attendance Management System.

It contains all functional, technical, architectural, API, business, frontend, backend, and AI documentation required for development.

No implementation should begin before the relevant documentation is finalized and approved.

---

# Repository Goals

- Maintain one authoritative documentation source.
- Keep backend and frontend synchronized.
- Prevent undocumented implementations.
- Support AI-assisted development (Kiro & Claude).
- Track project progress through milestones and phases.
