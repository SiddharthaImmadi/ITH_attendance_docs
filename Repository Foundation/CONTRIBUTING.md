# CONTRIBUTING GUIDE

## Repository Philosophy

Documentation drives development.

Code must always follow approved documentation.

---

## Branch Strategy

Documentation Repository

- Main branch contains approved documentation.

Implementation Repository

- Backend development branch.
- Frontend development branch.

---

## Rules

- Do not implement undocumented features.
- Do not change frozen documents.
- Discuss documentation changes first.
- Keep milestones synchronized.
- Keep TODO lists updated.

---

## Pull Requests

Every implementation PR should reference

- Phase
- Milestone
- Related documentation
