
# Regression Testing

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines regression testing principles.

Regression testing ensures that previously working functionality continues to operate correctly after changes.

---

# Regression Scope

Regression testing should include:

- Authentication
- Attendance
- Presence Monitoring
- Leave Management
- Reporting
- Administration

---

# Execution

Regression testing should be performed whenever significant functionality changes.

---

# Expected Outcome

Existing approved functionality shall continue to behave as documented.
