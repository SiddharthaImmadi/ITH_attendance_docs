
# Defect Management

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines how defects are identified, documented, and resolved.

---

# Defect Lifecycle

```
Reported

↓

Confirmed

↓

Assigned

↓

Resolved

↓

Verified

↓

Closed
```

---

# Defect Information

Each defect should include:

- Description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Severity
- Status

---

# Resolution

Resolved defects should be verified before closure.
