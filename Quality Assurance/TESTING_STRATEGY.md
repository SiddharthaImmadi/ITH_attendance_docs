# Testing Strategy

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the overall testing strategy for the project.

---

# Objectives

Testing should confirm:

- Requirements are implemented correctly.
- Business rules are enforced.
- APIs behave as documented.
- Existing functionality continues to work.

---

# Testing Levels

Testing includes:

- Unit Testing
- Integration Testing
- API Testing
- End-to-End Testing
- Regression Testing

---

# Test Execution

Tests should be executed throughout development rather than only before release.

---

# Automation

Automated testing should be used where practical.
