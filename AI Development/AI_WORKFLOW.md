
# AI Workflow

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the standard workflow AI assistants shall follow when implementing or modifying the project.

---

# Standard Workflow

```
Read Documentation

↓

Understand Requirements

↓

Explain Planned Changes

↓

Wait for Approval

↓

Implement Approved Scope

↓

Run Relevant Tests

↓

Validate Against Documentation

↓

Stop
```

---

# AI Responsibilities

Before implementation, AI shall:

- Review relevant documentation.
- Identify affected components.
- Explain the implementation plan.

During implementation, AI shall:

- Follow documented behavior.
- Keep changes focused.
- Preserve existing functionality.

After implementation, AI shall:

- Verify consistency.
- Report completed work.
- Report any remaining limitations.
