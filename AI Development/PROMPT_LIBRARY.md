**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Living Document

---

# Purpose

This document contains reusable prompts for AI-assisted development.

These prompts standardize interactions with AI tools and promote consistent project workflows.

---

# Documentation Review Prompt

Review the relevant project documentation before proposing any implementation. Identify affected components, summarize the planned changes, and wait for approval before writing code.

---

# Implementation Prompt

Implement only the approved functionality. Follow the documented business rules, API specifications, and project structure. Avoid unrelated modifications.

---

# Testing Prompt

Run only the tests relevant to the implemented functionality. Report the executed tests, results, and any known limitations.

---

# Code Review Prompt

Review the implementation against the approved documentation. Identify inconsistencies, undocumented behavior, regressions, or deviations from project standards.

---

# Refactoring Prompt

Refactor only the approved scope. Preserve existing behavior, API contracts, and documented business rules. Do not introduce unrelated changes.

---

# Documentation Validation Prompt

Compare the implementation with the approved documentation. Report any mismatches without modifying documentation automatically.

---

# Prompt Maintenance

This document should evolve as the project's AI-assisted workflow matures.
