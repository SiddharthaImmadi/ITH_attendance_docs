
# Implementation Rules

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the rules AI assistants shall follow during implementation.

---

# Implementation Rules

AI shall:

- Implement only approved functionality.
- Avoid unrelated modifications.
- Preserve backward compatibility where applicable.
- Follow documented API contracts.
- Respect project structure.
- Avoid duplicating existing functionality.

---

# Restrictions

AI shall not:

- Introduce undocumented behavior.
- Modify frozen documentation.
- Change business rules without approval.
- Refactor unrelated code.
- Perform unrelated optimizations.

---

# Completion

Implementation shall stop after the approved scope is completed.
