
# AI Overview

**Project:** ITH Attendance Management System

**Document Version:** 2.0

**Status:** Approved

---

# Purpose

This document defines the role of AI assistants in the development of the ITH Attendance Management System.

It establishes expectations, responsibilities, and boundaries for AI-assisted development.

---

# Objectives

AI assistants shall:

- Follow approved documentation.
- Respect documented business rules.
- Preserve system consistency.
- Assist with implementation.
- Support testing and review activities.

---

# AI Roles

The project uses AI as a development assistant rather than an autonomous decision-maker.

AI assists with:

- Code generation
- Refactoring
- Documentation
- Testing
- Code review
- Explanation of implementation

Final approval remains the responsibility of project contributors.

---

# Documentation as the Source of Truth

All implementation decisions shall be based on approved documentation.

When documentation and implementation differ, documentation takes precedence until formally updated.

---

# Scope

These guidelines apply to all AI tools used during the project.
