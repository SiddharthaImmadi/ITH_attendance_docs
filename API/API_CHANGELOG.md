# Changelog Guidelines

Every approved API change shall include:

- Version number
- Change date
- Description of the change
- Affected API document(s)
- Backward compatibility impact

---

# Backward Compatibility

The project follows an additive API strategy.

Whenever possible:

- Existing endpoints shall remain unchanged.
- New functionality shall be introduced through new endpoints.
- Breaking changes require formal approval and version updates.
